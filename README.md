# ⬡ SANZ SecureFace AI 🤖

> **Smart Attendance for the Next Generation 🚀**

The system automatically detects and recognizes faces in real-time and marks attendance securely — no manual work required.

## ⚙ How the System Works

```
1. 🆔  User registers face data
        ↓
2. 💾  System stores facial embeddings
        ↓
3. 📷  Live camera scans user face in real-time
        ↓
4. 🧠  AI compares face with stored embeddings
        ↓
5. ✅  Attendance is marked automatically
        ↓
6. 📄  Reports are generated instantly
```

### Recognition Thresholds

| Distance | Result | Action |
|----------|--------|--------|
| < 0.5 | ✅ Exact Match | Mark attendance |
| 0.5 – 0.7 | ⚠ Approx Match | Mark attendance |
| ≥ 0.7 | ❌ Not Matched | No action |
